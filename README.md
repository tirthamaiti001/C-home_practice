## 📂 𝘙𝘦𝘱𝘰𝘴𝘪𝘵𝘰𝘳𝘺 𝘚𝘵𝘳𝘶𝘤𝘵𝘶𝘳𝘦 & 𝘒𝘦𝘺 𝘗𝘳𝘰𝘨𝘳𝘢𝘮𝘴

The repository contains implementation files focusing on distinct logical and computational aspects of C:

### 🧱 𝗠𝗮𝘁𝗵𝗲𝗺𝗮𝘁𝗶𝗰𝗮𝗹 & 𝗟𝗼𝗴𝗶𝗰 𝗔𝗹𝗴𝗼𝗿𝗶𝘁𝗵𝗺𝘀
* **Armstrong_Number.c** - Checks if a given number is an Armstrong number.
* **Factorial.c** - Computes the factorial of a number using iterative or recursive approaches.
* **Prime_Number.c** - Determines whether a given number is prime.
* **Compound_Interest.c** - Calculates interest compounded over a given time frame.

### 📊 𝗣𝗿𝗮𝗰𝘁𝗶𝗰𝗮𝗹 𝗖𝗮𝗹𝗰𝘂𝗹𝗮𝘁𝗼𝗿𝘀 & 𝗨𝘁𝗶𝗹𝗶𝘁𝗶𝗲𝘀
* **Basic Calculator.c** - A foundational arithmetic application for standard calculations.
* **BMI_calculator.c** - Measures Body Mass Index based on user biometrics.
* **Mark_Grade.c & Mark_Grade_Adv.c** - Grade evaluation scripts using conditional rules.
* **Find Average.c** - Computes statistical averages of set inputs.

### 🔸 𝗦𝘁𝗿𝗶𝗻𝗴 𝗠𝗮𝗻𝗶𝗽𝘂𝗹𝗮𝘁𝗶𝗼𝗻
* **Count_Vowel.c** - Parses a character string to count vowel frequencies.
* **Remove_Space.c** - Trims whitespace elements out of a target string.

### 📐 𝗠𝗮𝘁𝗿𝗶𝘅 & 𝗔𝗿𝗿𝗮𝘆 𝗢𝗽𝗲𝗿𝗮𝘁𝗶𝗼𝗻𝘀
* **Rotate Matrix 90°.c** - Executes a clockwise 2D array transformation.
* **PrintDiagonal.c** - Isolates and prints the main diagonal elements of a matrix.
* **Sum of Boundary.c** - Accumulates the outer boundary elements of a matrix system.
* **Swap_Elements.c** - Interchanges values inside target memory array indexes.

### 𝗖𝗼𝗺𝗽𝗶𝗹𝗮𝘁𝗶𝗼𝗻 𝗦𝘁𝗲𝗽𝘀:
* Clone the codebase repository to your device: git clone https://github.com
* Navigate directly into the local directory path: C-home_practice
* Compile any desired .c implementation file (e.g., Prime_Number.c): gcc Prime_Number.c -o Prime_Number
* Execute your newly generated binary output:
*    On Windows: Prime_Number.exe
*    On Linux / macOS: ./Prime_Number
