C-Home Practice
📚Welcome to the C-Home Practice repository! This repository serves as a comprehensive log of my self-learning journey and foundational coding practice in the C programming language before and through the college 1st year. It features a wide variety of hands-on programs ranging from core basic mathematics to advanced multi-dimensional matrix operations and dynamic memory allocation.
📂 Repository Structure & Key Programs: The repository contains implementation files focusing on distinct logical and computational aspects of C:
🧮 Mathematical & Logic AlgorithmsArmstrong_Number.c – Checks if a given number is an Armstrong number.Factorial.c – Computes the factorial of a number using iterative or recursive approaches.Prime_Number.c – Determines whether a given number is prime.Compound_Interest.c – Calculates interest compounded over a given time frame.
📊 Practical Calculators & UtilitiesBasic Calculator.c – A foundational arithmetic application for standard calculations.BMI_calculator.c – Measures Body Mass Index based on user biometrics.Mark_Grade.c & Mark_Grade_Adv.c – Grade evaluation scripts using conditional rules.Find Average.c – Computes statistical averages of set inputs.
🔀 String ManipulationCount_Vowel.c – Parses a character string to count vowel frequencies.Remove_Space.c – Trims whitespace elements out of a target string.
🧱 Matrix & Array OperationsRotate Matrix 90°.c – Executes a clockwise 2D array transformation.PrintDiagonal.c – Isolates and prints the main diagonal elements of a matrix.Sum of Boundary.c – Accumulates the outer boundary elements of a matrix system.Swap_Elements.c – Interchanges values inside target memory array indexes.
🧠 Advanced Memory ManagementPractice_calloc().c – Explores contiguous dynamic allocation using calloc.Practice_dyn-arr.c – Creates and manages fully functional dynamic runtime arrays.
🛠️ Core Concepts ExploredThrough these custom programs, I have built a solid foundation in:Variables & Primitive Types (int, float, char)Control Flows (if-else branching, switch-case statements)Loop Structures (for, while, do-while loops)Dynamic Memory Management (Pointers, heap manipulation via calloc)Data Structuring (1D arrays, multi-dimensional matrices, and custom structures)
🚀 How to Run locally
Prerequisites: Make sure you have a C compiler installed on your local environment (such as GCC via MinGW on Windows, or standard Unix build utilities for macOS/Linux).

••• Compilation Steps:
Clone the codebase repository to your device: git clone https://github.com
Navigate directly into the local directory path: C-home_practice
Compile any desired .c implementation file (e.g., Prime_Number.c): gcc Prime_Number.c -o Prime_Number
Execute your newly generated binary output:
   On Windows: Prime_Number.exe
   On Linux / macOS: ./Prime_Number
